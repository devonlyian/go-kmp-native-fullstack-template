# 문서 동기화

[English](SKILL.md) | [한국어](SKILL.ko.md)

영어 `name.md`는 에이전트 기준본이고 같은 폴더의 `name.ko.md`는 사용자용 번역이다. 일반 개발은 영어만 읽는다. 한국어는 번역 수정·검토 또는 명시적 요청 때만 읽으며 이 스킬은 영향받는 문서 쌍에 한정한 예외다. 어느 언어에서든 수정을 시작할 수 있고 같은 변경에서 영어 기준본과 한국어 번역을 일치시킨다. 이 스킬과 AGENTS를 포함한 저장소의 관리 대상 Markdown에 적용하며, 빌드 산출물·의존성 캐시·로컬 검증 자료는 `tools/check-docs.py`에서 제외한다. 사용자와의 대화는 한국어로 유지한다.

1. 수정 전에 영향받는 각 문서의 두 버전과 관련 구현을 읽고 무관한 번역은 불러오지 않는다. 의미, 명령, 버전, 결과, 미검증 범위를 동일하게 유지한다. 과거 테스트 결과를 이번에 실행한 것처럼 표현하지 않는다.
2. 같은 변경에서 두 파일을 함께 갱신한다. 제목 아래에 언어 전환 링크를 추가한다. 문서 링크는 같은 언어로 연결하고 제목 앵커도 맞추되 코드 경로와 식별자는 유지한다. 이름 변경이나 삭제도 두 파일을 함께 처리한다. 영어 `AGENTS.md`와 `SKILL.md`가 에이전트 진입점이다.
3. 완성된 두 버전을 비교해 빠진 절, 사실, 명령, 깨진 링크를 확인한다. 해시 검사로 번역 품질을 판단할 수는 없다. 검사를 통과하려고 의미 없는 공백 수정만 하지 않는다.
4. 저장소 루트에서 `python3 tools/check-docs.py --record <document.md>`를 실행한다. 영어 또는 한국어 경로를 하나 이상 지정할 수 있다. 검토한 해시를 `docs/.translations.json`에 기록하며, 기존 쌍에서 한 언어만 변경됐다면 거부한다. 이름 변경은 한 쌍씩 별도로 실행하며 이전·새 경로를 모두 지정하고, 두 파일 삭제는 삭제한 영어 경로를 지정한다. 해시를 직접 수정하거나 검토하지 않은 번역을 기록하지 않는다.
5. `./tools/verify.sh structure`로 동기화 검사와 그 테스트까지 실행한다. 커밋 요청이 있으면 양쪽 문서와 manifest를 함께 포함한다. 변경 내용과 검사 결과를 보고하며 이 스킬이 commit이나 push 권한을 부여하지는 않는다.

예를 들어 개발 문서 목차 두 버전을 갱신한 뒤 다음을 실행한다.

```sh
python3 tools/check-docs.py --record docs/index.md
./tools/verify.sh structure
```

번역 API, 파일 감시 프로세스, 기기 전용 hook을 추가하지 않는다. 프로젝트 지침이 양쪽 수정을 유도하고 기존 CI 구조 검사가 누락된 파일이나 마지막 검토 이후 바뀐 내용을 차단한다. 이후 추가하는 Markdown도 검토된 문서 쌍이 필요하다.
