# Setup

[English](setup.md) | [한국어](setup.ko.md)

Choose one scope. Commands start at the repository root; each guide changes directory only inside a subshell.

- [Backend setup](../../backend/docs/setup.md): Go, Docker, PostgreSQL, and Atlas for the API and database.
- [App setup](../../app/docs/setup.md): JDK, Android SDK, and Xcode for Android, iOS, and shared KMP work.

Both scopes consume the one GraphQL SDL in `contracts/graphql/`. Set up and run both only for work that explicitly needs local end-to-end integration.
